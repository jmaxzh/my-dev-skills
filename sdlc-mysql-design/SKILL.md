# MySQL 数据表与 SQL 设计

## 适用范围

- 任务或项目上下文明确使用 MySQL，且涉及数据建模、表结构、SQL、索引、事务或并发控制的设计、编写、修改、审查或优化时，自动应用本技能，无须用户显式调用。
- 本技能独立使用，不依赖 SDLC 主流程。不得因通用数据库任务自动选定 MySQL，也不应用于仅涉及其他数据库的任务。

## 按需读取规则

- 处理适用任务前，读取并遵循 [MySQL 数据表与 SQL 设计规范](references/mysql-design.md)，按任务范围应用相关规则。
- 规则含义或适用方式不明确时，按主题读取 [MySQL 数据表与 SQL 设计示例](references/mysql-design-examples.md) 中的对应内容，无须默认加载全部示例。
